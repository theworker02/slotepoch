# slotepoch

Slot and reshape epoch text streams with deterministic transforms.

**Site:** https://theworker02.github.io/slotepoch/

## Install / run

```bash
git clone https://github.com/theworker02/slotepoch.git
cd slotepoch
node src/cli.js
node --test
```
